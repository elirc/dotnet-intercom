# Domain Glossary

The nouns of NetIntercom, where they live, and the non-obvious bit about each. When code and intuition disagree, this table wins (it was read from the source).

| Term | Definition | Defined in | Non-obvious bit |
| --- | --- | --- | --- |
| **Visitor** | An end user of a host site chatting via the widget; anonymous-by-cookie or identified | [Visitor.cs](../../../src/NetIntercom.Domain/Entities/Visitor.cs) | Identity = `AnonymousId` (cookie) *or* `ExternalId` (host-supplied, **unverified** — risk R1). `DisplayName` is computed, not stored. |
| **AgentUser** | A support team member; may be admin | [AgentUser.cs](../../../src/NetIntercom.Domain/Entities/AgentUser.cs#L5-L15) | `IsAdmin` is a flag, not a separate role table; both `agent` and `admin` claims are minted for admins ([TokenService#L51-L56](../../../src/NetIntercom.Infrastructure/Auth/TokenService.cs#L51-L56)). |
| **Conversation** | A thread between one visitor and the support org | [Conversation.cs](../../../src/NetIntercom.Domain/Entities/Conversation.cs) | A visitor's conversations are resumed by most-recent; a closed one + `StartNew` spawns a fresh one ([SendVisitorMessage#L64-L67](../../../src/NetIntercom.Application/Widget/SendVisitorMessage.cs#L64-L67)). |
| **Message** | One utterance: visitor, agent, or system | [Message.cs](../../../src/NetIntercom.Domain/Entities/Message.cs) | `IsInternalNote` messages are agent-only and never delivered to visitors (enforced in 3 places — see key flow 3). |
| **Internal note** | An agent-only message | [Message.IsInternalNote](../../../src/NetIntercom.Domain/Entities/Message.cs#L17-L18) | Notes don't touch SLA timers or last-message previews ([SendAgentMessage#L60-L65](../../../src/NetIntercom.Application/Conversations/SendAgentMessage.cs#L60-L65)). |
| **Team** | A group of agents; may have office hours and a default SLA | [Team.cs](../../../src/NetIntercom.Domain/Entities/Team.cs) | Exactly one team should be `IsFallback`; office hours are JSON in `OfficeHoursJson`, not a table. |
| **TeamMember** | Join row agent↔team, carrying the round-robin cursor | [Team.cs#L21-L30](../../../src/NetIntercom.Domain/Entities/Team.cs#L21-L30) | `LastAssignedAtUtc` *is* the round-robin state — null sorts first (never assigned = next up). |
| **Fallback team** | Receives conversations no rule claims, or claimed-but-out-of-hours | [Team.IsFallback](../../../src/NetIntercom.Domain/Entities/Team.cs#L9-L10) | If no fallback exists, router uses the oldest team ([ConversationRouter#L50-L51](../../../src/NetIntercom.Application/Routing/ConversationRouter.cs#L50-L51)). |
| **RoutingRule** | Priority-ordered keyword→team rule | [RoutingRule.cs](../../../src/NetIntercom.Domain/Entities/RoutingRule.cs) | Lower `Priority` wins (ascending); null `Keyword` = catch-all; match tests message body *and* source URL. |
| **OfficeHours** | Weekly windows in a timezone | [OfficeHours.cs](../../../src/NetIntercom.Domain/Entities/OfficeHours.cs) | Empty windows = always open; unknown timezone silently treated as UTC (risk: debugging scenario 2). |
| **SlaPolicy** | First/next response time targets (minutes) | [Sla.cs#L5-L10](../../../src/NetIntercom.Domain/Entities/Sla.cs#L5-L10) | A *team* default; copied onto a conversation as `SlaPolicyId` at routing time (`??=`, so a pre-set policy survives). |
| **SlaTimer** | A running deadline on a conversation | [Sla.cs#L12-L63](../../../src/NetIntercom.Domain/Entities/Sla.cs#L12-L63) | At most one Running at a time; kind is FirstResponse until the first public reply, NextResponse after. |
| **FirstResponse / NextResponse** | The two timer kinds | [SlaTimerKind](../../../src/NetIntercom.Domain/Enums.cs#L17-L21) | Determined by whether `FirstAgentReplyAtUtc` is set ([Conversation#L121](../../../src/NetIntercom.Domain/Entities/Conversation.cs#L121)). |
| **Breach** | A timer that passed its deadline while Running | [SlaTimer.MarkBreached](../../../src/NetIntercom.Domain/Entities/Sla.cs#L42-L51) | Detected by the minutely Hangfire job, not in real time; can happen on snoozed conversations (risk R9). |
| **Presence** | An agent's live status: Online / Away / Offline | [PresenceStatus](../../../src/NetIntercom.Domain/Enums.cs#L31-L36), [PresenceTracker](../../../src/NetIntercom.Api/Realtime/PresenceTracker.cs) | Computed in-memory from connections + heartbeats; 60s disconnect grace, 5min idle→Away. Not durable across restarts (despite the snapshot table — R11). |
| **PresenceSnapshot** | Persisted last-known presence | [PresenceSnapshot.cs](../../../src/NetIntercom.Domain/Entities/PresenceSnapshot.cs) | Written by the sweeper, **read by nothing** (risk R11). |
| **Viewer / collision** | Agents currently looking at a conversation | [PresenceTracker viewers](../../../src/NetIntercom.Api/Realtime/PresenceTracker.cs#L92-L127) | Drives "Sara is already viewing this" ([Inbox.tsx#L263-L265](../../../frontend/inbox/src/pages/Inbox.tsx#L263-L265)); in-memory, per-connection. |
| **CannedReply** | A saved reply inserted via `/shortcut` | [CannedReply.cs](../../../src/NetIntercom.Domain/Entities/CannedReply.cs) | Team-shared (`TeamId`) or personal (`AgentUserId`); the only soft-deletable entity. |
| **Placeholder** | `{{visitor.name}}` etc. in a reply | [PlaceholderRenderer](../../../src/NetIntercom.Application/Common/PlaceholderRenderer.cs) | Rendered **server-side** against conversation context; unknown/empty tokens left intact. |
| **RefreshToken** | Long-lived rotation credential | [AgentUser.cs#L17-L29](../../../src/NetIntercom.Domain/Entities/AgentUser.cs#L17-L29) | Stored as SHA-256 hash; rotated (revoked + reissued) on every use. |
| **Correlation id** | Per-request trace id | [CorrelationIdMiddleware](../../../src/NetIntercom.Api/Infrastructure/CorrelationIdMiddleware.cs) | Flows request→response header→Serilog→ProblemDetails; your handle for debugging across logs. |
| **Hub group** | SignalR delivery channel | [RealtimeNotifier](../../../src/NetIntercom.Api/Realtime/RealtimeNotifier.cs), hubs | `agents` (all agents), `conv:{id}` (viewers), `vconv:{id}` (a visitor's conversation), `visitors` (all widgets). |
