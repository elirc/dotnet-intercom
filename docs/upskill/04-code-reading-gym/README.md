# Module 04: Code Reading Gym

Reading code is a trainable skill distinct from writing it. These are reps.

| Page | Rep type |
| --- | --- |
| [01-annotation-drills.md](01-annotation-drills.md) | Annotate a real method's inputs/outputs/invariants/failure modes before reading hints |
| [02-trace-tables.md](02-trace-tables.md) | Hand-execute a flow row by row, tracking value shape and risk |
| [03-fake-code-contrasts.md](03-fake-code-contrasts.md) | Bad-vs-better pairs tied to real patterns here — spot the difference and name it |
| [04-review-katas.md](04-review-katas.md) | Review simulated PR diffs; produce blocking/important/optional findings |

Do annotation drills first (they build the vocabulary), then trace tables (they build patience), then fake-code contrasts and review katas (they build judgment). The katas are calibration for real code review.
